# unexcel

Excelブック (*.xlsx)をTSVまたはJSONとして展開するツールです。

## TSV出力モード（デフォルト）

標準出力または指定ディレクトリにTSV形式で出力します。

標準出力への出力時には、制御コードVT(Vertical Tab; 0x0b)およびFF(Form Feed; 0x0c)により複数シートを区切って出力します。

```
シート1のシート名<VT>
シート1のデータ(TSV)<FF>
シート2のシート名<VT>
シート2のデータ(TSV)<FF>
...
```

`-outdir=<出力先ディレクトリ>`で出力先ディレクトリを指定した場合、シートごとに `<出力先ディレクトリ>/<シート名>.tsv` ファイルを作成します。
シート名に使えない文字(`\ / : * ? " < > |`)は `_` に置換し、重複時は連番を付与します。


### オプション

- ヘッダはExcelの表示に準じたA,B,C.../1,2,3...を出力します。`-noheader`オプションにより非表示にできます。
- 計算結果ではなく計算式（例: `=SUM(A1:A10)`）を出力させたい場合は、`-raw`オプションを指定します。
- セル内のタブ・改行は `\t` `\n` に変換されます。


## JSON出力モード

`-json[=出力先ファイル名]`によりブック全体をJSON形式で出力します。
ファイル名未指定の場合は標準出力に、ファイル名を指定した場合はファイルに出力されます。
`-pretty`オプションでJSONを整形して出力します。

```json
{
	"シート名": {
		"A1": { "value": "200", "format": "0.0", "raw": "=SUM(B1,B2)" }
	}
}
```

## 入力の指定

- XLSXファイルのパスを指定する
- `-` を指定すると標準入力からXLSXデータを読み込む

```sh
# ファイルを指定して読み込み
unexcel sample.xlsx

# 標準入力から読み込み
curl https://example.com/download/example.xlsx | ./unexcel -
```


## ビルド

```sh
make
```
